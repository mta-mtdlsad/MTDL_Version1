Geographic land mask

File: ne_10m_land.geojson
Dataset: Natural Earth 1:10m Physical Vectors, Land polygons, version 5.1.1
Dataset information: https://www.naturalearthdata.com/downloads/10m-physical-vectors/
Project mirror used for the GeoJSON source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_land.geojson

Natural Earth states that its data is free for use in any type of project. This generalized
land mask is used only for platform-position plausibility checks and synthetic route generation.
It is not an authoritative navigation chart, survey, coastline product, or operational safety
boundary. Update the dataset and rerun geographic tests when the training region or required
coastline precision changes.
